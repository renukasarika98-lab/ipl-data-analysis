# 🏏 IPL Data Analysis (2008–2022)

## Overview
Exploratory Data Analysis of IPL matches and player 
performance using Python and Power BI.

## Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- Power BI
- Dataset: IPL Complete Dataset (Kaggle)

## Key Insights
1. Mumbai Indians have the most wins in IPL history
2. Most captains choose to field after winning the toss
3. Winning the toss gives only a slight match advantage
4. Virat Kohli is the all-time leading run scorer
5. AB de Villiers dominates Player of the Match awards
6. IPL expanded significantly from 2011 onwards

## Files
- analysis.py — Python EDA code
- ipl_dashboard.pdf — Power BI Dashboard
- charts — all visualization images

## How to Run
1. Download IPL dataset from Kaggle
2. Run analysis.py in VS Code
3. Open ipl_dashboard.pdf to view dashboard

Note: deliveries.csv is not uploaded due to file size 
limits. Download it from Kaggle link above.
